# YouTube Video Sharing via iPhone

This project is a mobile user guide focused on sharing YouTube videos using the YouTube app on iPhone.

The guide was created to demonstrate clear end-user documentation, accessibility-aware instructions, and step-by-step procedural writing for non-technical users.

---

## Documentation Scope

This project includes documentation for:

- Navigating the YouTube mobile app
- Sharing videos through iPhone
- Using built-in iOS sharing features
- Accessibility considerations for VoiceOver users
- Troubleshooting common sharing issues

---

## Key Features

- Step-by-step mobile instructions
- User-focused writing style
- Accessibility-aware documentation
- VoiceOver compatibility guidance
- Clear navigation workflows
- Beginner-friendly formatting

## Tools Used

- Markdown
- GitHub
- iPhone YouTube app workflows

## Purpose of Project

This project was created to demonstrate technical writing skills related to end-user documentation, accessibility-focused writing, mobile application workflows, and instructional content organization.
